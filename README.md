# VCode IDE — Mobile Web Development Redefined

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![Platform](https://img.shields.io/badge/Platform-Android-green.svg)](https://developer.android.com)

**VCode** is a powerful, lightweight, and fully integrated mobile IDE built specifically for web developers on Android. Whether you're a student learning the ropes or a professional needing to make a quick hotfix on the go, VCode provides a desktop-class editing experience in the palm of your hand.

Built with a focus on speed, aesthetics, and Git-first workflows, VCode turns your Android device into a portable web development workstation.

---

## ✨ Key Features

### 🚀 Professional Code Editor
*   **Multi-Language Support:** Optimized for HTML, CSS, JavaScript, and JSON.
*   **Smart Syntax Highlighting:** Powered by a custom high-performance engine using **JetBrains Mono**.
*   **Intelligent Autocomplete:** Context-aware suggestions for HTML tags, CSS properties, and JavaScript keywords.
*   **Advanced Editor Logic:**
    *   Auto-closing brackets and HTML tags.
    *   Smart indentation and bracket matching.
    *   Find and Replace with Regex support.
    *   Word wrap and customizable font sizes.

### 🌿 Native Git & GitHub Integration
VCode isn't just an editor; it's a full Git client.
*   **Full Git Lifecycle:** Initialize repositories, stage changes, commit, and manage branches natively.
*   **GitHub Ready:** Securely connect your GitHub account using Personal Access Tokens (stored in Android Keystore).
*   **Sync with Ease:** Push, pull, and fetch from remote repositories.
*   **Visual Diff Viewer:** See exactly what changed before you commit with a beautiful side-by-side or unified diff view.
*   **Commit History:** Browse your project's story with a clean, navigable timeline.

### 🌐 Live Web Preview
*   **Instant Feedback:** Run your HTML projects instantly with an integrated high-performance WebView.
*   **In-App or Browser:** Choose to preview your work inside VCode or launch it in your favorite mobile browser.
*   **JSON Viewer:** Beautifully formatted and syntax-highlighted previews for JSON data.

### 📁 Smart Project Management
*   **Project-First Workflow:** Organize your work into isolated projects, each with its own settings and Git state.
*   **File Tree Navigation:** Easily manage nested folders and files with a fast, intuitive sidebar.
*   **Templates:** Start new projects instantly with "Blank", "HTML" or "HTML+CSS+JS" templates.
*   **Snippet Manager:** Save your most-used code blocks and insert them with a single tap.

### 🎨 Modern & Responsive UI
*   **Material Design 3:** A clean, modern interface following the latest Android design standards.
*   **Sora Typography:** Beautiful UI typography for a premium feel.
*   **Full Dark Mode:** Work comfortably at any time of day with a deeply integrated dark theme.

---

## 🛠️ Built With

VCode is engineered for performance and reliability using a modern Android stack:
*   **Language:** 100% Java (Optimized for Android 6.0+)
*   **Architecture:** MVVM (ViewModel, LiveData, Repository Pattern)
*   **Git Core:** [JGit](https://www.eclipse.org/jgit/)
*   **Design:** Material Components for Android (MDC)
*   **Performance:** Off-main-thread syntax highlighting and Git operations for zero UI lag.
